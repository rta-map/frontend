# rta-map Frontend

## Description
Technologies: Vue.js + Vite, SCSS, Vue-Router, Pinia, TypeScript

### Create file .env and fill it with var (your api address)
```sh
VITE_API_BASE_URL=url
```
### Project Setup
```sh
bun install
```
### Compile and Hot-Reload for Development
```sh
bun dev
```
### Compile and Minify for Production
```sh
bun run build
```
